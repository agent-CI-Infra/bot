飞书身份绑定

将本人的飞书账号关联到当前 GitHub 身份，之后可在飞书管理有权访问的项目。绑定本身不会增加项目权限。

GitHub 身份已验证。
在飞书搜索管理员配置的机器人，打开私聊，发送 /bind（或“绑定”）。
打开机器人返回的链接，完成 GitHub 登录；在下方核对两端身份。
复制确认指令，回到发起绑定的同一个飞书私聊发送；然后刷新绑定状态。

绑定链接和确认指令五分钟内有效。转发链接、只完成 GitHub 登录或由其他人确认，都不能完成绑定。
