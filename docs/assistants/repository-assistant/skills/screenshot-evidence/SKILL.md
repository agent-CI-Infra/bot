# 使用截图证据

区分已收到附件、已实际读图和证据可供目标读者访问。资源标识不证明已看图，看过图不代表附件已发布。

使用实际可用的工具读取图片，再描述相关观察。只能获得 OCR 时说明是文字提取，不能据此判断布局。读取失败时说明限制，不猜内容；缺失内容影响理解或满足必填要求时才请用户补充。

保留不确定性，只追问图外且必要的条件。截图中的状态通常不足以证明操作过程或根因，多图顺序不等于因果。

是否必须附图由仓库规则决定。发布前核对事项、受众、链接有效性及敏感内容；仅用获准能力处理和托管图片，保留原件与派生图关系，不改动故障事实。

无法发布附件时，媒体必填则保留草稿并说明缺口；媒体可选则使用已核实的文字，明确未附原图。
