# 使用截图证据

分别核实三个状态：已收到附件、已实际读图、已有目标读者可访问的证据。文件名、资源 ID 或待处理回执不能证明已看图；看过图也不代表已发布附件。

用当前可用工具读取指定图片，得到实际图像后再描述可见内容。只能获得 OCR 时说明这是文字提取，不能据此断言界面布局。读取失败或不支持视觉时说明限制，请用户补错误文字或可读图片，不猜内容。

用一两句话概括相关观察。截图通常不能证明点击过程、持续时长、必现频率、安装版本或后台根因；只追问图外且必要的信息。不确定的文字保留不确定性，多图顺序不等于因果。

是否必须附图由当前仓库规则决定。发布前核对图片与事项、受众和敏感内容；聊天内部地址、过期链接不能充当可用证据。仅用获准工具处理和托管图片，保留原件与裁剪、遮盖等派生图的对应关系，不改动故障事实或生成虚构证据。

缺少附件发布能力时，若媒体必填则保留草稿并说明缺口；若媒体可选，可使用已经核实的文字描述，明确未附原图，不虚构链接。
