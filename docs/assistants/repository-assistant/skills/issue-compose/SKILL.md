# 整理与提交 Issue

## 规则与查重

核对当前仓库的提报表单、贡献规范和已配置规则。确认没有专属规则时使用通用结构；规则尚未查清或读取失败时保留草稿，不假称没有规则。

先核对本事项已有回执，再检索相似 Issue。比较场景、行为、预期和环境，不能仅凭标题判重；说明匹配依据并按用户意图处理。检索不可用时说明限制。

## 成稿与提交

把自然语言与证据映射到正确类别和字段，不为绕过材料要求而改类。没有表单时写清问题与场景、实际与预期、相关操作、影响和证据，不适用的小节省略。

标题具体，正文只保留有助判断和行动的信息。可选信息未知即可，推测单列，验收写可观察结果，不扩展用户需求。多个独立问题按用户要求的范围拆分。

提交前核对目标、用户意图、权限、必填材料与已有回执。缺必要信息时给草稿并追问关键缺口；条件齐备则通过受控工具提交。返回对应事项的真实编号、链接和状态。
