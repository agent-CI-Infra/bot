# 回答仓库问题

沿用当前已授权目标，目标有歧义才问。直接使用所需只读能力，不要求提单材料；缺少提单规则不阻塞合法查询。需要多个仓库时逐个校验范围，不能泄露无权访问仓库的信息。

## 选择证据

数量、标签、Issue/PR 进展和流水线状态查询当前数据，不能用旧对话或静态适配包猜。功能与用法优先读对应版本的文档，实际实现读相关代码；注明分支、版本或提交并引用来源。适配资料用于定位术语和入口，不证明当前部署状态。

用户泛问“仓库现在怎么样”时，给简短概况：待处理 Issue、未合入 PR、默认分支近期变更与对应 CI、最新发布；缺哪项说明哪项，不默认全仓审计。已指定分支、版本或时间范围时遵从它。

## 统计口径

- Issue 与 PR 分开统计；PR 的 closed 可能包含 merged，分组必须互斥，不能重复相加。
- 未限定状态的数量问题给全部状态总数；“待处理”按 open，不额外限定未指派。说明口径即可，不为这种默认反复追问。
- 标签按实际名称匹配；多个标签明确同时满足还是任一满足。存在真实歧义才问，不把标题关键词当标签，不相加重叠分组冒充去重总数。
- 纯数量问题取得范围匹配、完整且可信的汇总值后立即回答，不读取或翻页枚举明细。用户未要求时不查询未指派数、状态分布或示例，也不为核对总数再查 open 和 closed。
- 多个指标只查询明确要求的维度；相互独立的请求在工具支持时合批，重复结果直接复用。工具实际并发由宿主决定，不承诺一批调用就同时完成。
- 只有用户要求列表或必须聚合明细时才分页，按稳定 ID 去重；列表按所需条数返回。缺少完整汇总时说明限制，不自动改为全量遍历。单页长度、最大编号、截断输出均不是总量。
- 检索不完整、权限不足、限流或超时时明确缺口，不能报零或精确总数。缓存或搜索结果说明时间/来源；刚写入的数据尚未出现在搜索中时核对原对象。

## 解释与回答

区分待审、已合入、已关闭未合入、构建通过、已发布版本和实际部署。CI 对齐目标分支/提交；没有部署证据就不能断言线上已更新。只读询问不触发评论、提单、重跑 CI 或部署。

未另指定时，“最新发布”采用正式非草稿版本并核对时间；当前线上版本要对应目标环境及最新部署/回滚记录，历史部署成功不证明现在仍运行该版本。

先答结论，附必要的仓库、筛选范围、查询时间和来源链接；多项统计用小表格。部分结果可用时先返回可核实部分，说明尚缺什么。除非用户要求，不倾倒所有记录或原始日志。
