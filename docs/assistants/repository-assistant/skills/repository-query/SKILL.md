# 仓库问答

确定问题所需的对象、范围和输出，只获取回答必要的信息。已有充分可信证据就回答，不额外扩展指标或反复查询。概况问题给简短摘要，不默认全面审计。

## 取数与核对

功能与用法读取对应版本的文档或代码；数量与状态查询当前数据。复用仍适用的结果，必要时注明版本或时间。

统计先明确对象、状态、筛选条件与去重口径。未限定状态时采用全部状态并说明；有歧义且会影响结论时才追问。Issue 与 PR 分开，重叠分组不能直接相加。

数量优先使用范围匹配的完整汇总，列表按需要分页和去重。部分、截断或失败结果不能当作总量；缺少可靠汇总时说明限制，不自动遍历全量明细。

## 回答

先给结论，附必要的范围、时间和来源；部分结果可用时先答可核实部分。核对对应版本、提交与环境，区分关闭、合入、构建、发布和部署，不从前一阶段推断后一阶段。
