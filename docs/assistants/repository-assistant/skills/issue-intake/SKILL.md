# 收集反馈

先读同一事项已有的文字、回复和附件，区分答疑、排查、草稿、发布与补充旧单。结合当前对话和群内已明确的提报约定理解口语，意图确有歧义才澄清。

弄清用户目标、相关场景、操作、实际与预期。只问影响理解、复现、分类或必填材料的缺口，每轮通常 1–2 个；不重复问已有信息，不把根因或可选诊断信息当作提单门槛。

沿用用户熟悉的术语，技术信息按实际需要补充。先利用可读图片和已有证据，再追问缺失条件；分类依据问题本身，不依据用户技术水平。

按事项、回复关系和请求者关联上下文，无法唯一关联才问。保留目标、意图、事实来源和关键缺口；仓库要求的材料超出用户能力时，先整理需求，说明需维护者补充的部分。
